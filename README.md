# CFE · University of Michigan Center for Entrepreneurship

A public guide to the Center for Entrepreneurship at the University of Michigan. The first screen is the 2026 Princeton Review and Entrepreneur placement: Midwest No. 1, national No. 4 undergraduate, national No. 5 graduate. The rest of the site is the system behind that number: ENTR courses, the Entrepreneurial Leadership Program, NSF I-Corps, EHour, the graduate certificate, and the Perot Jain TechLabs.

The CFE Guide answers from those published facts. It does not invent deadlines or replace an advisor.

## Develop

```bash
npm install
npm test
npm run dev
```

## Deploy on Vercel

Import this GitHub repository in Vercel. The framework preset is Next.js. No environment variables are required.

Optional: set `NEXT_PUBLIC_SITE_URL` to the production URL so the sitemap and social cards use the live domain.

Program details are summarized from the Center’s public pages and the November 12, 2025 Princeton Review announcement. Confirm registration, rooms, and deadlines at [cfe.umich.edu](https://cfe.umich.edu/).
